### 1.常量指针和指针常量有何区别？

常量指针，也就是底层const：const int* p 或 int const* p，被指向的数据不可更改，无法直接被用于拷贝构造其它非常量指针 如: 

```cpp
int x{2};
const int* p = &x;
int* q = p // error 
```
指针常量，也就是顶层const: int *const p，指针本身是const，它指向的位置不可修改

### 2.引用和指针如何选择？

⚠️   
引用和指针本质都是内存地址概念，都可以对变量进行就行修改。
如果有存在不指向任何对象的可能，用指针，因为引用必须绑定值。

#### qwen

引用必须初始化、不能为空、不能重新绑定；  
指针可 nullptr、可重定向、可多级间接。  
sizeof时，引用得到对象大小，指针得到指针大小  

怎么选？  
能用引用就用引用（尤其 const T& 传参避免拷贝）；需要“可为空 / 可重定向 / 多级间接 / 延迟初始化”时用指针。



### 3.nullptr和NULL有何区别？

nullptr表示空指针，类型是`nullptr_t`。而NULL可以表示空值也可以表示0, 本质是个宏，有二义性。

### 4.RAII的核心机制是什么？

RAII是资源获取即初始化，本质是把资源的生命周期绑定在对象上。RAII核心机制一个是C++的栈对象自动析构————栈帧销毁时，也就是脱离作用域、函数返回或抛出异常时自动调用析构函数，另一个是C++的析构函数机制————保证对象销毁时一定会执行析构函数

### 5.new/delete与malloc/free有何区别？

new/delete是操作符，而malloc/free是库函数。new/delete都会执行两步————new是分配内存、构造对象，delete时析构对象，释放内存。而malloc/free只分配内存/释放内存。当发生错误时，new会返回std::bad_alloc，而malloc返回NULL

### 6.栈和堆有何区别？

⚠️  
栈体积小，由系统自动管理，处理速度快；而堆体积大，需要手动管理内存，处理速度比栈慢。一般的对象、函数地址等存在栈上，涉及到new的存在堆上

#### deepseek

栈存放函数参数、局部变量、返回地址、寄存器保存等。进入函数时分配栈帧，函数返回时自动释放。局部对象离开作用域自动析构。由编译器/运行时自动管理，后进先出，分配释放极快但空间小  

堆/自由存储区通过程序员 new/delete、malloc/free 手动管理，或用智能指针管理。运行时动态分配，空间大但是慢，容易碎片和泄漏

*栈帧：程序调用函数时，系统分配的临时栈上内存空间就叫栈帧。 栈帧存储局部变量，函数参数、返回地址、寄存器保存等*

### 7.栈和堆的内存分配方式有何不同？

#### qwen

**栈分配**本质是移动栈指针，一条指令即可完成，O(1)、绝对连续、永不碎片、无需元数据、无锁、线程私有。
**堆分配**运行时由堆分配器管理，维护空闲块链表/bins，采用首次适配/最佳适配等策略，大块用 mmap、小块用 brk/sbrk；每个块带 header/cookie 记录大小与状态，需对齐；多线程下有 arena/线程缓存以减少锁竞争；会产生内部/外部碎片；回收时需合并相邻空闲块。因此堆分配比栈慢一个数量级左右，且是非确定性的。

### 8.全局、局部、静态局部对象何时初始化和销毁？

❌  
已初始化的全局对象，局部对象和静态局部对象存在.data段，未初始化或值为0的话存在.bss段。

|场景|全局对象|局部对象|静态局部对象|
|--|--|--|--|
|初始化|不确定，可能在编译期也可能在运行期|执行到相关语句时才初始化|惰性初始化，需要用到时才初始化，并且全局初始化一次|
|销毁|整个程序结束时|脱离局部作用域时|整个程序结束时|

#### qwen

局部（自动）变量在栈上，进入作用域时才分配，离开时释放，根本不在任何数据段里。只有全局变量和 static 变量才落在 .data（已初始化非零）或 .bss（未初始化/初始化为 0）。


### 9.类成员初始化顺序由什么决定？


#### deepseek

1. **虚基类**：按深度优先、从左到右初始化。

2. **直接基类**：按继承列表中的声明顺序初始化。

3. **非静态数据成员**：按在类定义中的声明顺序初始化，和初始化列表顺序无关。

4. **构造函数体**：最后执行。

```cpp
struct A{
	A(){ cout << "A\n"; }
	~A(){ cout << "~A\n"; }
};
struct B{
	B(){ cout << "B\n"; }
	~B(){ cout << "~B\n"; }
};

struct C : A{
	B b1;
	B b2;
	int num1;
	int num2;

	C(int m, int n) : b2(), b1(), num2(n), num1(num2 + m){ // 按在类定义中的声明顺序初始化(b1, b2, num1, num2)，和初始化列表顺序无关。

	}
};

int main(){
	C c(1, 10);
	cout << c.num1 << std::endl; // 未初始化
    cout << c.num2 << std::endl; // 10
}

// output: A B B 2(未初始化/UB) 10 ~B ~B ~A
```

### 10.构造中途抛异常，已构造成员如何释放？


#### qwen

1. 对象本身的析构函数不会被调用（因为对象尚未构造完成，不属于完整对象）。 如第九题中，若C的构造函数中抛出异常，不会调用C::~C()

### 11.什么是移动语义？

### 13.拷贝构造、拷贝赋值、移动构造、移动赋值有何区别？

拷贝构造是在构造对象时，将一个对象的资源拷贝给另一个，被拷贝的对象不受任何影响，性能差。
拷贝赋值是在一个对象已经构造好的情况下，先释放自己的资源，再拷贝另一个对象的资源，被拷贝的对象不受任何影响，性能差。
移动构造是在构造对象时，将一个对象的资源转交给另一个”偷取资源“的对象，被”偷取资源“的对象变为将亡值。通常标记为noexcept，性能好。
移动赋值是在一个对象已经构造好的情况下，先释放自己的资源，再将接收另一个对象转交的资源，转交资源的对象变为将亡值。通常标记为noexcept，性能好。

### 14.构造和赋值有何区别？

构造的前提是对象本身不存在。
赋值的前提是对象本身已存在。

###  16.函数重载和重写有何区别？

重载是针对同名函数的，根据传入参数的类型或者数量，❌返回不同的值，进行不同的处理。
重写是针对继承与多态的，一般是子类重写父类的虚方法。

#### deepseek

重载：同作用域、同名、参数列表不同，编译期绑定。  
重写：派生类重写基类虚函数，签名相同，运行期多态。

### 17.什么是函数隐藏？

函数隐藏是子类与父类有同名但不同实现的函数，父类的函数没有标记为virtual，导致调用为子类的，父类的这个函数被隐藏。
或者父类标记为virtual，但子类重写的时候函数签名不同，导致父类函数被隐藏。

#### deepseek

派生类同名函数“遮蔽”了基类同名函数，导致通过派生类作用域直接访问时只看到派生类版本。  

两种原因：基类没标 virtual；或标了 virtual 但子类签名不同（此时是隐藏而非重写，是 bug 高发点）。  

想用被隐藏的基类版本，要显式加作用域或 using

### 18.函数隐藏会隐藏基类哪些函数？

#### deepseek

派生类中只要声明了与基类同名的成员，就会在派生类作用域中隐藏基类中所有同名函数，不是只隐藏签名相同的那个

### 23.构造函数能否为虚函数，为什么？

不可以。
⚠️查询虚函数表依赖虚表指针，而虚表指针是对象构造完后才有的。如果一个构造函数是虚函数，那么该构造函数构造对象时，对象还没构造完，虚指针还没初始化

#### deepseek

vptr 在构造期间逐步设置，基类构造时指向基类虚表。但构造函数不能虚，因为调用构造函数时对象还不存在，无法通过对象查虚表。

### 24.基类析构函数为何通常声明为虚函数？

如果不声明为虚函数的话，基类析构的时候无法通过虚函数表找到子类的析构函数，子类不会析构从而导致内存泄漏

### 26.vector和list底层存储有何区别？

vector是连续存储，❌list是随机存储

#### qwen

- vector：连续动态数组，支持随机访问，缓存极其友好，尾插均摊 O(1)，中间插入删除 O(n) 且需搬移。
- list：双向链表，节点分散在堆上，非连续，只支持双向迭代器，不支持随机访问（没有 operator[]）。
- 实践结论：除非频繁在中间插入删除且需持有迭代器，否则 vector 往往更快（节点分配开销 + 缓存命中率差）。

### 27.vector如何扩容？

寻找一片更大的内存，将原来的元素全部拷贝或移动到这块内存上

### 28.不同编译器的vector扩容策略是否相同？

#### qwen

- 不相同，标准只要求 push_back 均摊 O(1)，倍数由实现决定。
- libstdc++(GCC) 约 2 倍，MSVC 约 1.5 倍，libc++(Clang) 约 2 倍。
- 1.5 倍的好处是旧内存块有机会被回收复用（接近黄金比例），2 倍则永远不会复用之前释放的块。

### 29.迭代器何时失效？

⚠️  不详细  
发生扩容、插入或删除时，不同类型的容器失效情况不同

#### deepseek

迭代器本质是指向容器内部某块内存/某个节点的“位置标记”。只要这个位置的内存变了、没了、搬家了，迭代器就失效。

1. 内存有没有重新分配？ 有 → 全失效。

2. 元素有没有被移动/删除？ 被移动或删除的位置及之后 → 失效。

3. 容器是不是节点式(list、map、set、unordered_*)？ 是 → 只有被删节点失效。

### 30.vector插入元素如何影响迭代器？

看发不发生扩容，不发生的话该位置及以后的迭代器失效，发生扩容则全部失效。

### 31.list插入、删除如何影响迭代器？

插入不影响迭代器，删除则删除位置的迭代器失效

### 32.push_back与emplace_back有何区别？

### 33.如何释放vector内存，而非仅清空元素？

#### deepseek

clear() 只销毁元素，size() 变成 0，但 capacity() 通常不变，内存并没有还给系统。

```cpp
// 创建一个空临时 vector，和 v 交换；临时对象拿到原来的内存，析构时释放掉。
vector<T>().swap(v);

// C++11, 非强制请求，标准不保证一定释放到 size()
v.shrink_to_fit();


// 移动赋值一个空 vector
v = std::vector<int>();
```

### 39.undefined reference是哪个阶段的错误？

#### deepseek

链接阶段的错误, 链接器找不到某个符号的定义。

常见原因：

1. 函数声明了但没定义；

2. 定义了但对应的 .o 或库没参与链接；

3. 库顺序不对（静态库有依赖顺序，被依赖的放后面）；

4. C/C++ 混编没加 extern "C"，导致符号名被 C++ name mangling；

5. 模板实现放在 .cpp 里，其他翻译单元实例化不到；

6. 链接了错误架构或错误版本的库。

### 41.-O2、-O3会做哪些优化？

#### qwen

- -O2 常见：内联（inlining）、循环不变量外提、常量传播与折叠、死代码消除、公共子表达式消除、尾调用优化、寄存器分配与变量提升、指令调度/重排、基本块合并、-fomit-frame-pointer。
- -O3 在 -O2 基础上更激进：更高的内联代价阈值、循环展开（unroll）、树向量化/自动 SIMD 化、函数克隆、更激进的别名分析。

### 42.静态库和动态库各有哪些优缺点？

#### deepseek

- 静态库 .a/.lib：链接时把用到的目标文件拷进可执行文件。 体积大、部署简单（单文件即可运行）、无运行时加载开销、升级需重新链接、多进程运行不共享代码内存、符号天然隔离。

- 动态库 .so/.dll：运行时由动态链接器加载。 代码段可被多进程共享内存页，体积小、可共享、可热更新，但有依赖、路径、版本兼容问题，有 PLT/GOT 开销

### 43.构造函数为何优先用初始化列表而非函数体赋值？

#### deepsseek

初始化列表是“直接构造成员”，函数体赋值是“先默认构造、再赋值”。对类类型成员来说，后者多一次默认构造和一次赋值，效率更低；而且 const 成员、引用成员、无默认构造的成员、基类子对象都必须在初始化列表中初始化。

### 44.enum和enum class有何区别？

#### deepseek

* enum class 是 C++11 的强类型、强作用域枚举。它的枚举值不会污染外层作用域，必须用 E::Value 访问；不会隐式转换为整数，不同类型之间不能混用，因此更安全。  
* 普通 enum 的枚举值会暴露在外层作用域，可以隐式转 int，容易命名冲突和类型混用。两者都可以指定底层类型，但 enum class 未指定时默认底层类型是 int，普通 enum 未指定时由实现决定。现代 C++ 更推荐 enum class，除非需要兼容 C 或旧代码。  
* enum struct 和 enum class 等价。


```cpp
enum eColor{ red, blue };
enum class ecColor{ red, blue };

int a1 = red;    // 0
int a2 = ecColor::red;  // error, can't implicit converse
int a3 = static_cast<int>(ecColor::red);

enum class A { X };
enum class B { X };

if(A::X == B::X){}  // error, can't compare with different types

// specify type
enum E1 : uint8_t { J, K };
enum class E2 : uint8_t { J, K };
```

|维度|enum|enum class (C++11)|
|--|--|--|
|作用域|||
|隐式转换|可隐式转换为整型|禁止隐式转换，需`static_cast`|
|类型安全|弱|强|

### 46.【代码题】两个有序数组A、B，A长m+n，前m项有效、后n项为0占位，B有n项。如何用C++原地合并到A，保持有序且额外空间O(1)？

```cpp
using namespace std;

// [1,2,4,0,0] [3,6]
// [1,2,3,4,6]

// [4,5,6,0,0] [1,2]
// [1,2,4,5,6]

// 没原地，回去等通知
void merge(vector<int>& vecA, vector<int>& vecB){
    if(vecA.empty() || vecB.empty())    return;

    int n = vecB.size();
    int m = vecA.size() - n;
    int k{0};

    for(int i = m; i < m + n; i++){
        vecA[i] = vecB[k++];
    }

    sort(vecA.begin(), vecB.begin());
}

// true
void Merge(vector<int>& vecA, vector<int>& vecB){
    if(vecA.empty() || vecB.empty())    return;

    int n = vecB.size();
    int m = vecA.size() - n;

    int left1{m - 1}, left2{m + n - 1}, right{n - 1};
    while(left1 >= 0 && right >= 0){
        if(vecA[left1] >= vecB[right]){
            vecA[left2--] = vecA[left1--];
        }else{
            vecA[left2--] = vecB[right--];
        }
    }

    while(right >= 0){
        vecA[left2--] = vecB[right--];
    }
}
```
